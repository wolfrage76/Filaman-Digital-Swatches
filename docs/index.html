Firmware 0.22.0 · Chrome or Edge

Flash the panel that matches the card.

Digital Swatch System runs on the Elecrow CrowPanel 7″ and the Waveshare ESP32-S3-Touch-LCD-7. The images are not interchangeable. Stay in the card for the board in your hand.

CrowPanel 7″

Elecrow · 4 MB flash · CH340 USB

  1. Install a CH340 driver if the serial port does not appear.
  2. Connect a USB data cable.
  3. Use the buttons in this card only.

Keep settings

Updates firmware and leaves Wi‑Fi, FilaMan, and the admin password. If asked to erase, choose No.

Factory reset

Full install. Erases saved settings. Use for a first flash or a blank screen.

Then scan the QR code on the panel, or open http://crowpanel-xxxx.local/ (last four of the MAC address)

Waveshare 7″

ESP32-S3-Touch-LCD-7 · 16 MB flash · native USB

  1. Plug into the board USB port.
  2. No port? Hold BOOT, tap RESET, release BOOT.
  3. Do not use the CrowPanel buttons.

Keep settings

Waveshare app update only. Leave erase off so Wi‑Fi and FilaMan stay.

Factory reset

Full 16 MB image. Use for a first flash or recovery.

Then scan the QR code on the panel, or open http://waveshare-xxxx.local/ (last four of the MAC address)

After the flash finishes, power-cycle the panel, join 2.4 GHz Wi‑Fi on the touchscreen, and set the FilaMan URL and API key at the address above. This page needs Chrome or Edge over HTTPS, or http://localhost. Setup notes are in the project README.
