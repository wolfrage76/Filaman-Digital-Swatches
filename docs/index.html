Filaman Digital Swatches

USB flash for 7″ ESP32-S3 panels: Elecrow CrowPanel and Waveshare ESP32-S3-Touch-LCD-7. Use the section that matches your hardware — the images are not interchangeable.

Firmware 0.21.0 ESP32-S3 Chrome / Edge

Elecrow CrowPanel 7″

  1. Install the CH340 USB-serial driver if your OS needs it.
  2. Connect the CrowPanel with a USB data cable.
  3. Pick an option below and select the CrowPanel serial port.
  4. Wait for the flash to finish, then power-cycle or reset the panel.

Keep Settings

Updates firmware without wiping NVS. Keeps Wi‑Fi, FilaMan URL/key, printer choice, and OTA password. If the installer asks to erase the device, choose No.

Factory Reset

Full install and erase. Wipes all saved settings. Use for first-time flash or a blank screen after a bad update.

Default hostname after setup: http://crowpanel.local/

Waveshare ESP32-S3-Touch-LCD-7

  1. Connect the board on its USB connector (Chrome / Edge).
  2. If the port does not appear: hold BOOT, press RESET, release BOOT.
  3. Pick Keep Settings or Factory Reset below — do not use the CrowPanel buttons.

Keep Settings

App update for Waveshare only. Keeps Wi‑Fi and FilaMan settings when the installer is told not to erase.

Factory Reset

Full 16 MB image for Waveshare. Use for first flash or recovery.

Default hostname after setup: http://waveshare-ams.local/

After flashing

Join Wi‑Fi on the device, then open the panel’s .local address (or its IP) to set the FilaMan URL and API key. Needs Chrome or Edge (Web Serial) over HTTPS (or http://localhost).
