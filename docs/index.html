Filaman Digital Swatches

USB flash for the Elecrow CrowPanel 7″ (ESP32-S3). Choose whether to keep Wi‑Fi / FilaMan settings or wipe the device clean.

Firmware 0.20.19 ESP32-S3 Chrome / Edge
  1. Install the CH340 USB-serial driver if your OS needs it.
  2. Connect the CrowPanel with a USB data cable.
  3. Pick an option below and select the CrowPanel serial port.
  4. Wait for the flash to finish, then power-cycle or reset the panel.

Keep Settings

Updates firmware without wiping NVS. Keeps Wi‑Fi, FilaMan URL/key, printer choice, and OTA password. If the installer asks to erase the device, choose No / don’t erase — that is what preserves settings.

Factory Reset

Full install and erase. Wipes all saved settings. Use for first-time flash, a blank screen after a bad update, or when Keep Settings cannot recover the panel.

Needs Chrome or Edge (Web Serial) and this page over HTTPS (or http://localhost). Safari and Firefox are not supported. Blank screen after Keep Settings? Use Factory Reset once, then set up Wi‑Fi / FilaMan again.

After flashing

If you factory-reset (or this is a new panel), join Wi‑Fi on the device, then open http://crowpanel.local/ to set the FilaMan URL and API key. With Keep Settings, the panel should come back on the same Wi‑Fi and config.
